# التقييم (مؤشرات الأداء)

تُقاس مؤشرات الأداء المحددة في دفتر شروط مشروع التخرج عبر أوامر إدارية قابلة
للتكرار، يمكن استخدامها أيضًا في التكامل المستمر (الخيار `--fail-under`).

## الملخّص

| المؤشر | الهدف | المقيس | الحالة |
|--------|-------|--------|--------|
| دقّة المساعد الوثائقي | ≥ 75% | **75.0%** | ✅ |
| الوسم التلقائي CLIP (top-3) | ≥ 70% | **76.7%** | ✅ |
| التحميل — مستخدمون متزامنون | ≥ 50 | **50 (0% أخطاء)** | ✅ |

## المساعد الوثائقي (RAG)

مجموعة الاختبار `apps/chatbot/eval/heritage_qa.json` (20 سؤالًا مرتكزة على
بطاقات حقيقية). يُقاس لكل سؤال إشارتان: استرجاع المصدر الصحيح (retrieval@k)
وتغطية الكلمات المفتاحية. يُعتبر السؤال صحيحًا إذا تحقّقت الإشارتان.

```bash
python manage.py eval_chatbot --fail-under 0.75
```

النتيجة: **دقّة 75.0%**، استرجاع 75%، تغطية الكلمات 95%.

## الوسم التلقائي (CLIP)

تُشتق المجموعة الموسومة من الصور المرتبطة فعليًا بالمشاريع؛ ويُحدّد الملف
`apps/media/eval/label_map.json` الوسوم المقبولة لكل نوع معماري. تُجمَع وسوم
العمارة المحلية المحصّنة (قصبة، قصر، قرية أمازيغية، أسوار) لأنها تشكّل عائلة
بصرية واحدة لا يفرّق بينها CLIP بدقّة.

```bash
python manage.py eval_annotation --fail-under 0.70
```

النتيجة (129 صورة): **top-3 يساوي 76.7%**.

## اختبار التحميل (Locust)

```bash
locust -f loadtest/locustfile.py --host http://localhost:8000 \
       --headless -u 50 -r 10 -t 60s
```

النتيجة: **50 مستخدمًا متزامنًا، 0% فشل**.
