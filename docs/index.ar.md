# مركز التراث (PatrimoineHub)

**منصّة وطنية تشاركية لتوثيق التراث المعماري الجزائري.**

يجمع مركز التراث الخبراء والباحثين والمواطنين حول مرجع موحّد للتراث المبني في
الجزائر: بطاقات توثيقية متعددة اللغات (عربي / فرنسي)، مشاريع تشاركية بإصدارات،
بحث متقدّم، مساعد وثائقي (RAG)، وسم تلقائي للصور، وتصدير وفق المعايير التراثية.

## الفضاءات الأربعة

| الفضاء | الجمهور | الوظائف الأساسية |
|--------|---------|------------------|
| **العام** | الزوّار | الفهرس، الخريطة، البحث، البطاقات العمومية، المحادثة |
| **التطبيق** | الباحثون / الخبراء | المشاريع، المحرّر، الإصدارات، النزاعات، التصدير |
| **الإدارة** | المدراء | المستخدمون، المشاريع، الإحصاءات، الإشراف |
| **المصادقة** | الجميع | التسجيل، تأكيد البريد، المصادقة الثنائية، OAuth2 |

## الوحدات ذات القيمة العالية

- **بحث Elasticsearch** متعدد اللغات (محلّلات عربي/فرنسي)، أوجه، تمييز، وضع هجين
  (BM25 + إعادة ترتيب دلالي عبر pgvector).
- **المساعد الوثائقي (RAG)**: LangChain + Mistral، مع الاستشهاد بالمصادر.
- **الوسم التلقائي (CNN)**: تصنيف الصور دون أمثلة مسبقة عبر CLIP.
- **تصدير معياري**: PDF/A-1b، Dublin Core، CIDOC-CRM (JSON-LD)، بيان IIIF 3.0.
- **عرض ثلاثي الأبعاد / واقع معزّز** عبر QR.
- **المراقبة**: Prometheus + Grafana، Sentry.

## المعايير المُعتمدة

- **Dublin Core** — البيانات الوصفية الأساسية.
- **CIDOC-CRM v7.2** — الرسم الدلالي JSON-LD للموارد.
- **IIIF Presentation 3.0** — بيانات صور المشاريع.
- **PDF/A-1b (ISO 19005-1)** — تصدير قابل للأرشفة.
